# Weekly preparation and season stakes

Before each game, choose personal development (the existing rotating objective and XP), teammate work (three receptions by a selected RB, WR or TE for +1 catching, capped at 97, instead of objective XP), or a coach challenge (win, six pass attempts, two QB passing/rushing touchdowns and no interceptions for 1.5 times objective XP and two additional confidence points). Normal game XP remains unchanged. Skipping the choice keeps the existing objective.

Selections save immediately, may change before kickoff, and lock while a game is active. They are scoped by career stage, season, week and postseason round. Rewards settle with the existing once-only game result; loading or reviewing a recap cannot repeat them. Existing careers need no migration.

Home shows current conference position, the actual qualification cutoff, remaining regular-season games and nearby contenders. College uses the existing conference-wins-first standings and top-two conference championship qualification. Pros use the existing top-four conference playoffs. These are current positions, not mathematical clinch/elimination predictions. Postseason messaging reflects advancement, elimination and the champion. Recaps save the before/after position after all weekly simulations settle.

Tests cover college/pro choices, reloads, locks, failed objectives, caps, confidence, legacy defaults, duplicate results and postseason summaries. Browser coverage uses 844x304, 667x375 and 844x390 viewports with deterministic result fixtures. Physical-device gameplay remains user testing.

Draft presentation and deeper rookie/pro decisions are the next phases, not part of this change.
